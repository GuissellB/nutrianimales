Consultar `persona5/README.md` y `persona5/docs/integracion_n8n.md`. Ejecutar desde la raíz de `nutrianimales`, en un entorno de laboratorio autorizado.

- A5: SELECT masivo sin exportación → D7 **central**, después del sondeo de baseline.
